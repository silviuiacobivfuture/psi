# psi

The psi estate (psizone.ro): its apps, packages and tools, on the SEB platform.

```bash
pnpm install
pnpm build        # every project
pnpm affected     # lint, type-check, test, build for what changed
```

New app: create `apps/<name>/` (see CLAUDE.md, "Adding an app").
The platform is provisioned from SEB: `estate/` holds this estate's inputs to it.
